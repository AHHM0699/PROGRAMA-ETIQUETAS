Escribe {campo} en un texto, código o QR para pedirlo al imprimir. {#} numera cada copia. Arrastra los elementos sobre la etiqueta para moverlos. Una plantilla base (★) no se pisa: al guardarla con cambios se crea una etiqueta nueva.

Al poner otro rollo: elige su perfil y toca Cambiar a este rollo (ajusta el sensor y calibra). Si la impresión sale corrida, imprime la prueba de márgenes y ajusta el origen: cada 0,125 mm es un punto. Si al calibrar avanza mucho papel y se prende el LED rojo, cambia la lectura del sensor (reflectiva ↔ transmisiva).
